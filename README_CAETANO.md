# CAETANO — Casa de Carnes

Sistema client-side para GitHub Pages/PWA/EXE, adaptado para açougue/casa de carnes.

## Funções principais
- PDV e vendas de balcão.
- Encomendas com status e alerta ao dono quando fica pronto.
- Estoque por lote, validade e local físico.
- Importação XML NF-e com espelho fiscal: fornecedor, itens, NCM, CEST, CFOP, EAN, descontos, totais e duplicatas.
- Entrada manual sem NF com boletos/parcelas editáveis.
- Financeiro com contas a pagar/receber, DRE básica e exclusão auditada.
- Clientes, fornecedores e CEP automático.
- Produção/desossa/cortes com perdas/aparas.
- Módulos por unidade no Superadmin.
- IA local thIAguinho com regra de verdade: não inventa preço, estoque ou financeiro sem registro.
- Perfil equipe sem valores financeiros.
- Tema claro/escuro com contraste em inputs.

## Valores verdadeiros
O sistema não traz preços fictícios de carne. Preços, custos e margens devem ser cadastrados pelo usuário com dados reais da operação.
